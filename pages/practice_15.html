ПРАКТИКАЛЫҚ ЖҰМЫС №15

Тақырыбы: Жоба қорғау (Python қолданбасы)

1. Практикалық жұмыстың мақсаты

  • Студенттің курс барысында алған білімдерін жүйелеу;
  • Python тілін қолдана отырып шағын қолданбалы жоба дайындау;
  • Модульдер, файлдар, функциялар, ООП, шарттар, циклдер, тізімдер, сөздіктер сияқты тақырыптарды біріктіріп пайдалану;
  • Бағдарламаны презентациялау және қорғау дағдыларын дамыту;
  • Командалық немесе жеке жұмыс ішінде жауапкершілік, логикалық ойлау, креативтілік қабілеттерін жетілдіру.

2. Жобаға қойылатын жалпы талаптар

Студент жасаған Python жобасы келесі талаптарға сай болуы тиіс:

✔ Техникалық талаптар

  • Код Python 3.x нұсқасында жазылуы тиіс;
  • Кемінде 3–6 модуль немесе Python бөлімдері қолданылуы тиіс:
    • шартты операторлар
    • циклдер
    • функциялар
    • файлмен жұмыс
    • тізімдер, сөздіктер
    • ООП (міндетті емес, бірақ ұсынылады)
  • Жоба толық жұмыс істейтін болуы тиіс (қателіксіз);
  • Пайдаланушы интерфейсі:
    • CLI (консоль) форматында
    • немесе GUI (Tkinter) форматында
  • Код құрылымы таза, түсініктемелер жазылған болуы керек.

✔ Құжаттық талаптар

Студент қорғауға дайындайды:

    1. Жоба атауы мен мақсаты

    2. Қолданылатын технологиялар мен модульдер

    3. Бағдарламаның жұмыс схемасы (алгоритм)

    4. Код үзінділері

    5. Нәтижелер (скриншоттар)

    6. Қорытынды

3. Жоба тақырыптарының үлгі тізімі

Студент төмендегі ұсыныстар ішінен таңдай алады немесе өз идеясын ұсына алады.

1) Студенттік база (Student Manager)

  • студент қосу / жою
  • іздеу
  • файлға сақтау
  • статистика шығару

2) Жеке қаржы есептегіші (Budget Tracker)

  • кіріс/шығыс енгізу
  • айлық есеп
  • график (қалаған жағдайда)
  • файлға жазу

3) Мини-калькулятор (CLI немесе GUI)

  • төрт амал
  • тригонометрия (math модулі)

4) Тест/викторина жүйесі

  • сұрақтар тізімі
  • балл есептеу
  • файлға нәтиже жазу

5) Кітапхана жүйесі (Library App)

  • кітап қосу
  • кітапты беру/қайтару
  • ID арқылы іздеу

6) Дүкен тауарларын басқару (Shop Inventory)

  • тауар қосу
  • бағасын өзгерту
  • ең қымбат/ең арзан тауарды табу

7) GUI қолданбасы (Tkinter)

  • калькулятор
  • күнтізбе
  • тіркелу терезесі (login)
  • мини-game: "Click counter", "Guess the number"

4. Студентке арналған орындалу қадамдары

1-қадам. Жоба идеясын таңдау және сипаттау

  • Жоба атауы
  • Мақсаты
  • Не үшін қажет?
  • Қандай функциялар орындалады?

2-қадам. Жоба құрылымын дайындау

  • модульдер
  • папкалар
  • main.py

3-қадам. Алгоритм жазу

Псевдокод немесе блок-схема түрінде.

4-қадам. Негізгі кодты жазу

Кемінде мына бөліктер болуы тиіс:

    ✔ функциялар

    ✔ циклдер

    ✔ if/elif/else

    ✔ тізім, сөздік немесе кортеж

    ✔ файлмен жұмыс

    ✔ қажет болса ООП

    ✔ GUI қолданса — Tkinter класс құрылымы

5-қадам. Жобаны тестілеу

  • Жөндеу
  • Қатені өңдеу (try/except)

6-қадам. Қорғауға презентация дайындау

Презентацияда:

  • Жобаның мақсаты
  • Интерфейс (скриншот)
  • Кодтың маңызды бөліктері
  • Нәтиже
  • Қорытынды

5. Қорғау барысында бағалау критерийлері

Критерий Ұпай
Жоба идеясының өзектілігі 5
Python функционалын толық қолдану 10
Код сапасы (түсініктеме, құрылым, тиімділік) 10
Файлмен/модульдермен/функциялармен жұмыс 10
GUI қолданылса +5 қосымша ұпай -
Жоба презентациясының сапасы 5
Жобаны ауызша қорғауы 5
Жалпы: 45–50 ұпай

6. Қорғауға арналған студент сұрақтары (эксперт сұрауы мүмкін)

    1. Жобаңызды не үшін таңдадыңыз?

    2. Бағдарламаның негізгі функциялары қандай?

    3. Қандай модульдер немесе кітапханалар қолдандыңыз?

    4. Файлмен жұмыс қалай ұйымдастырылған?

    5. Қандай деректер құрылымын таңдадыңыз және неге?

    6. Егер GUI болса, Tkinter-де қандай виджеттер қолданылды?

    7. Қате өңдеу қалай жасалған?

    8. Жобаны әрі қарай жетілдіру мүмкін бе?

7. Студент шығаратын нәтижелер (output)

  • Жұмыс істейтін бағдарлама
  • Код файлы (.py)
  • Презентация (PowerPoint, Google Slides)
  • Жоба туралы қысқа есеп (1–2 бет)
  • Қосымша файлдар (мәліметтер, txt, json т.б.)

8. Практикалық тапсырма түрінде студент орындайтын нақты міндет

Тапсырма: Python тілінде шағын қолданба жасап, оны презентация арқылы қорғаңыз. Бағдарлама кемінде 5 функционалдық мүмкіндікті орындауы тиіс.

Мысалы (студенттік база):

    1. студент қосу

    2. студентті жою

    3. іздеу

    4. барлық студенттер тізімін шығару

    5. файлға сақтау / файлдан оқу

9. Академиялық адалдық

  • Жоба — студенттің өз еңбегі болуы тиіс;
  • Интернеттен алынған кодтың бөліктері болған жағдайда түсіндіріліп берілуі керек;
