Лекции по Python

Изучайте Python шаг за шагом: от основ до профессионального уровня.

10 лекция. Модульдер және стандартты кітапханалар

1. Модуль дегеніміз не?

Модуль (module) — бұл Python файлында орналасқан функциялар, айнымалылар, класс және басқа код бөліктерінің жинағы. Модульдер кодты құрылымдауға, қайта қолдануға және программаны бөліктерге бөлуге көмектеседі.

Мысал модуль:

my_module.py:

def hello():
    print('Сәлем!')

2. Модульді импорттау

Модульді импорттау тәсілдері:

  • import module_name
  • import module_name as mn
  • from module_name import function
  • from module_name import *

3. Стандартты кітапханалар

Python көптеген дайын кітапханалармен бірге келеді. Бұл кітапханалар стандартты кітапханалар деп аталады және оларды орнатпай-ақ қолдануға болады.

Кітапхана Қызметі Мысалы
math Математикалық функциялар math.sqrt(25)
random Кездейсоқ мәндер генерациялау random.randint(1,10)
datetime Күн және уақытпен жұмыс datetime.datetime.now()
os Операциялық жүйемен әрекеттесу os.listdir()
sys Python жүйелік параметрлері sys.version

4. Маңызды стандартты модульдер

  • math — математикалық функциялар
  • random — кездейсоқ сандар
  • datetime — уақыт, күн
  • os — файлдар және жүйе
  • sys — Python конфигурациясы
  • json — JSON форматымен жұмыс
  • statistics — статистикалық функциялар

5. Модуль жасау және пайдалану

Модульді өзіңіз жасау үшін жай ғана .py кеңейтімі бар файл құрасыз және оның ішінде функциялар, айнымалылар және кластар аласыз.

Мысал:

my_math.py:

def add(a, b):
    return a + b

main.py:

import my_math
print(my_math.add(5, 3))

6. Практикалық тапсырмалар

    math модулін қолданып, √, sin, cos функцияларын қолданып есеп шығарыңыз.

    random модулімен кездейсоқ пароль генераторы жасаңыз.

    datetime модулімен ағымдағы күнді форматтап шығарыңыз.

    Өз модуліңізді жасап, екі функция жазыңыз.

    json модулімен сөздікті JSON файлына сақтаңыз.
