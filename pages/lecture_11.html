11 лекция. Файлдармен жұмыс (ашу, оқу, жазу)

1. Файл дегеніміз не?

Файл — деректерді тұрақты түрде сақтау үшін қолданылатын құрылым. Python тілінде файлдармен жұмыс жасау үшін арнайы функциялар қолданылады.

2. Файлды ашу (open)

Файл ашу синтаксисі:
f = open('filename.txt', 'mode')

Режим Түсіндірме
'r' Оқу (read)
'w' Жазу (write), файлды тазалап жазады
'a' Қосу (append), файлдың соңына жазады
'r+' Оқу және жазу
'b' Бинарлық режим (binary)

3. Файлдан оқу тәсілдері

    1) Бір жол оқу:
    line = f.readline()

    2) Барлық жолдарды оқу:
    lines = f.readlines()

    3) Толық оқу:
    text = f.read()

4. Файлға жазу

Мысал:

f = open('data.txt', 'w')
f.write('Hello!')
f.close()

5. with операторымен файл ашу

with операторы файлды автоматты түрде жабуға мүмкіндік береді, сондықтан қауіпсіз.

with open('file.txt', 'r') as f:
    data = f.read()

6. Файлға қосымша жазу

with open('log.txt', 'a') as f:
    f.write('New line\n')

7. Практикалық мысалдар

    Мысал 1: Файлдан барлық мәтінді оқу.

    Мысал 2: Жаңа файлға мәтін жазу.

    Мысал 3: Файлға лог қосу.

    Мысал 4: Бір жолды оқу және шығару.

    Мысал 5: Бірнеше жолды тізім ретінде оқу.

8. Практикалық тапсырмалар

    Файлға 5 жол мәтін жазыңыз.

    Файлды оқып, барлық жолдарды нөмірлеп шығарыңыз.

    Файлдан сөз санын есептейтін бағдарлама жазыңыз.

    Файлға студенттердің аты-жөнін сақтап, қайта оқып шығарыңыз.

    Файлдың соңына уақыт белгісімен лог қосатын код жазыңыз.
