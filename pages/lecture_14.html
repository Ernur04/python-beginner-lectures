14 лекция. Класс мұрагерлігі (inheritance) арқылы бағдарлама құру

1. Кіріспе: Мұрагерлік деген не?

Мұрагерлік (inheritance) – объектіге бағытталған программалауда (OOP) жаңа класты бұрынғы класс негізінде құру механизмі. Бұрынғы класс – базалық (ата-ана, parent, base class) Жаңа класс – туынды (балалық, child, derived class).

Негізгі идея:

    Ортақ қасиеттер мен әдістерді бір рет базалық класста жазамыз

    Басқа кластар соларды «мұраға алады» және қажет болса кеңейтеді немесе қайта анықтайды.

Артықшылықтары:

    Кодты қайталамау (code reuse)

    Құрылымдың түсініктілігі

    Үлкен жүйені кіші бөліктерге бөлу

    Қолдау және өзгерту жеңілдейді

2. Негізгі терминдер (қысқаша)

  • Base class / Parent class – бастапқы класс
  • Derived class / Child class – базалық кластан мұра алатын класс
  • Method overriding – әдісті қайта анықтау
  • super() – ата-ананың әдісін шақыру
  • is-a байланысы – «A – бұл B-нің бір түрі» (Dog – бұл Animal).

3. Қарапайым мысал: Базалық және туынды класс

3.1. Базалық класс – «Жануар»

class Animal:
    def __init__(self, name):
        self.name = name

    def info(self):
        return f"{self.name} – жануар"

    def sound(self):
        return "Бір дыбыс шығарады"

Мұнда:

  • Animal – базалық класс
  • name – қасиет (attribute)
  • info() және sound() – әдістер (methods)

3.2. Туынды класс – «Ит»

class Dog(Animal):
    def __init__(self, name, breed):
        # базалық класс конструкторын шақырамыз
        super().__init__(name)
        self.breed = breed

    # әдісті қайта анықтау (overriding)
    def info(self):
        return f"{self.name} – ит, тұқымы: {self.breed}"

    def sound(self):
        return "Гав-гав!"

Пайдалану:

dog1 = Dog("Бөрі", "Неміс овчаркасы")

print(dog1.info())    # Бөрі – ит, тұқымы: Неміс овчаркасы
print(dog1.sound())   # Гав-гав!

Талдау:

  • Dog(Animal) – Dog класы Animal-дан мұра алады
  • super().__init__(name) – ата-ананың __init__ методын шақырады
  • info() және sound() әдістерін қайта анықтадық.

4. Мұрагерлік түрлері

4.1. Бірлік мұрагерлік (Single inheritance)

Тек бір базалық класстан мұра алу:

class A:
    pass

class B(A):
    pass

4.2. Көптік мұрагерлік (Multiple inheritance) – тек қысқаша

Python-да бір класс бірнеше базалық кластан мұра ала алады:

class Flyable:
    def fly(self):
        print("Ұша алады")

class Swimmable:
    def swim(self):
        print("Жүзе алады")

class Duck(Flyable, Swimmable):
    pass

d = Duck()
d.fly()   # Ұша алады
d.swim()  # Жүзе алады

Бұл – қуатты мүмкіндік, бірақ аса абайлап қолдану керек, күрделілігі артады.

5. Әдістерді қайта анықтау (Method overriding)

Туынды класта базалық кластың әдісін өз нұсқамызбен ауыстыра аламыз.

Жалпы схема:

class Parent:
    def greet(self):
        print("Ата-ана: Салем!")

class Child(Parent):
    def greet(self):
        print("Бала: Сәлеметсіз бе!")
Пайдалану:
p = Parent()
c = Child()

p.greet()  # Ата-ана: Салем!
c.greet()  # Бала: Сәлеметсіз бе!

Мұнда Child класы greet әдісін overriding жасады.

6. super() функциясын қолдану

Кейде ата-ананың функционалын толық жоймай, үстіне қосымша нәрсе қосуды қалаймыз.

class Person:
    def __init__(self, name):
        self.name = name

    def info(self):
        return f"Адам: {self.name}"

class Student(Person):
    def __init__(self, name, student_id):
        super().__init__(name)        # ата-ананың __init__-ін шақырамыз
        self.student_id = student_id

    def info(self):
        base_info = super().info()    # ата-ананың info() әдісін шақырамыз
        return f"{base_info}, студент ID: {self.student_id}"

Пайдалану:

s = Student("Айжан", "IS-23-05")
print(s.info())
# Адам: Айжан, студент ID: IS-23-05

Класс мұрагерлігі – күрделі жүйелерді ретті түрде, қайталанбайтын кодпен жазуға көмектесетін негізгі OOP құралы.

Есте сақтаңыз:

    Мұрагерлік – «is-a» қатынасы бар кезде қолданылады

    Ортақ функционал – базалық класста

    Нақты ерекшеліктер – туынды кластарда

    super() – ата-ананың коды мен жаңа кодты біріктіру құралы

    Әдістерді қайта анықтау арқылы (overriding) – әр кластың өзіндік мінез-құлқын жасаймыз.
