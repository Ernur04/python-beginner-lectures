ПРАКТИКАЛЫҚ ЖҰМЫС №14

Тақырыбы: GUI интерфейс жасау (Tkinter графикалық интерфейсі)

1. Практикалық жұмыстың мақсаты

  • Python тілінде графикалық интерфейс (GUI) ұғымын түсіну;
  • Tkinter кітапханасы арқылы қарапайым терезе (window) құру;
  • Негізгі виджеттермен жұмыс: Label, Button, Entry, Text;
  • Орналастыру әдістерін (pack, grid) қолдану;
  • Пайдаланушы әрекетіне жауап беретін функциялар (оқиғалар, event handler) жазу;
  • Қарапайым форма, есептегіш, мини-калькулятор сияқты қолданбалы GUI бағдарламалар жасауға дағдылану.

2. Қажетті бағдарламалар

  • Python 3.10+
  • Tkinter (Python-мен бірге келеді)
  • PyCharm / VS Code / IDLE

3. Теориялық бөлім (қысқаша)

3.1 GUI деген не?

GUI (Graphical User Interface) — пайдаланушы бағдарламамен терезе, батырма, мәтіндік өріс, меню сияқты графикалық элементтер арқылы жұмыс істейтін интерфейс.

Python-да ең жиі қолданылатын GUI кітапханалардың бірі — Tkinter.

3.2 Tkinter-ді импорттау және терезе құру

import tkinter as tk   # қысқаша атау

window = tk.Tk()       # Негізгі терезе
window.title("Менің алғашқы GUI-ім")
window.geometry("400x300")   # Ені x Биіктігі

window.mainloop()      # Терезені ашық ұстау циклі

Маңызды: mainloop() – бағдарлама “терезені күту режимінде” ұстап тұратын шексіз цикл.

3.3 Негізгі виджеттер

1) Label — жазу (мәтін)

label = tk.Label(window, text="Сәлем, студент!", font=("Arial", 14))
label.pack()

2) Button — батырма

def say_hello():
    print("Батырма басылды!")

btn = tk.Button(window, text="Бас", command=say_hello)
btn.pack()

command – батырма басылғанда шақырылатын функция.

3) Entry — бір жолды енгізу өрісі

entry = tk.Entry(window, width=30)
entry.pack()

Мәнін оқу:

text = entry.get()

4) Text — көп жолды мәтін

txt = tk.Text(window, height=5, width=40)
txt.pack()

3.4 Виджеттерді орналастыру

    1. pack() – қарапайым, үстіне/астына/оң/сол жағына

    2. grid(row, column) – кесте түрінде орналастыру

    3. place() – координата бойынша (бұл жұмыста негізінен pack және grid жеткілікті)

Мысалы:

label.grid(row=0, column=0)
entry.grid(row=0, column=1)
button.grid(row=1, column=0, columnspan=2)

4. Практикалық жұмыс қадамдары

1-қадам. Жаңа файл ашу

Файл атауы: gui_basic.py

import tkinter as tk

window = tk.Tk()
window.title("GUI практика №14")
window.geometry("400x300")

window.mainloop()

2-қадам. Label және Button қосу

import tkinter as tk

def hello():
    label.config(text="Сәлем, Python GUI!")

window = tk.Tk()
window.title("GUI демо")
window.geometry("400x200")

label = tk.Label(window, text="Батырманы басыңыз!", font=("Arial", 14))
label.pack(pady=10)

button = tk.Button(window, text="Сәлем де", command=hello)
button.pack(pady=10)

window.mainloop()

3-қадам. Entry + Button + Label

Пайдаланушы аты-жөнін енгізіп, батырма басқанда Label-де шығару. 

import tkinter as tk

def show_name():
    name = entry.get()
    label_result.config(text=f"Сәлем, {name}!")

window = tk.Tk()
window.title("Аты-жөн енгізу")
window.geometry("400x200")

entry = tk.Entry(window, width=30)
entry.pack(pady=5)

btn = tk.Button(window, text="Көрсету", command=show_name)
btn.pack(pady=5)

label_result = tk.Label(window, text="")
label_result.pack(pady=5)

window.mainloop()

5. Практикалық тапсырмалар

Тапсырмаларды күрделендіре отырып орындауға болады.

Тапсырма 1. Қарапайым сәлемдесу терезесі

GUI терезе жасаңыз:

  • Жоғарында Label: "Python GUI-ге қош келдіңіз!"
  • Астында "Жабу" деген батырма, оны басқанда терезе жабылсын (window.destroy()).

Тапсырма 2. Енгізу/шығару формасы

Терезеде:

  • "Атыңыз:" деген Label
  • Жанында Entry
  • "Қарсы алу" батырмасы
  • Батырма басылғанда: төменде "Сәлем, <аты>!" деп Label-ге жазылады.

Тапсырма 3. Қосынды есептейтін мини-калькулятор

Терезеде:

  • Сан 1: Label + Entry
  • Сан 2: Label + Entry
  • "Қосу" батырмасы
  • Нәтиже Label-де "Нәтиже: ..." деп көрсетілсін.

Кеңес:

a = int(entry1.get())
b = int(entry2.get())

Тапсырма 4. Grid орналасуын қолдану

grid() арқылы кішкентай форма жасаңыз:

row column 0 column 1
0 "Логин:" Entry
1 "Пароль:" Entry
2 Button "Кіру"

Батырманы басқанда консольге "Login clicked" деп жазылсын.

Тапсырма 5. Text виджетін қолдану

Терезеде:

  • Үлкен Text алаңы
  • "Тазалау" батырмасы

Батырма басылғанда Text ішіндегі барлық мәтінді өшіріңіз:

txt.delete("1.0", tk.END)

Тапсырма 6. Шартпен жұмыс жасайтын GUI

Entry-ге студенттің балын енгізу (0–100).

"Бағаны шығару" батырмасын басқанда Label-де:

  • 90–100 → "A"
  • 75–89 → "B"
  • 60–74 → "C"
  • < 60 → "Өткен жоқ"

Тапсырма 7. Түсті ауыстыратын батырма

Терезеде Label тұрады. 3 батырма: "Қызыл", "Жасыл", "Көк". Әр батырманы басқанда Label фон түсі өзгереді:

label.config(bg="red")

Тапсырма 8. Қарапайым “санағыш” (counter)

  • Label: "Санау: 0"
  • +1 батырмасы → санды 1-ге арттырады
  • -1 батырмасы → санды 1-ге кемітеді
  • label үздіксіз жаңарып отырады.

Тапсырма 9. “To-Do List” мини-қосымша (қарапайым нұсқа)

  • Entry — тапсырма енгізу
  • "Қосу" батырмасы
  • Төменде Listbox немесе Text ішінде тапсырмалар тізімі көрсетілсін.

(Егер Listbox қиын болса, Text-пен де жасауға болады: жаңа жолға жазу.)

Тапсырма 10. “About” терезесі

Басты терезеде "Бағдарлама туралы" батырмасы болсын. Оны басқанда жаңа кішкентай терезе (tk.Toplevel) ашылып, ішіне бағдарлама туралы қысқаша ақпарат шықсын.

6. Қателер және оларды түзету

Қате Себебі Шешімі
Терезе ашылмайды mainloop() жоқ Соңында window.mainloop() жазу
Батырма жұмыс істемейді command-ке дөңгелек жақшамен шақырып қойған (command=func()) Тек атауын беру: command=func
Мәтін шықпайды entry.get() қолданылмаған Entry-ден мәнді оқып, Label-ге беру
Виджет көрінбейді pack()/grid() шақырылмаған Орналастыру әдісін қолдану
Қате: TclError Виджет жойылған, бірақ әлі қолданылып жатыр Логиканы тексеру, қажетсіз destroy жасамау

7. Бақылау сұрақтары

    1. GUI деген не және Tkinter қандай рөл атқарады?

    2. Tk(), mainloop() функциялары не үшін қажет?

    3. Негізгі виджеттерді атаңыз (кемі 3–4).

    4. pack() және grid() айырмашылығы қандай?

    5. Батырмаға функцияны қалай байланыстырамыз (command)?
