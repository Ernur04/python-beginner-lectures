ПРАКТИКАЛЫҚ ЖҰМЫС №4

Тақырыбы: Шартты конструкциялармен есептер шығару (if / elif / else)

1. Практикалық жұмыстың мақсаты

  • Python тіліндегі шартты операторларды қолдануды үйрену;
  • if, elif, else конструкцияларын түрлі есептерде пайдалану;
  • Салыстыру және логикалық операторларды шебер қолдану;
  • Тармақталған алгоритмдер құруға дағдылану;
  • Қарапайым және күрделі шарттарды біріктіріп есеп шығару машығын қалыптастыру.

2. Қажетті бағдарламалар

  • Python 3.10+
  • PyCharm, VS Code немесе Jupyter Notebook
  • Windows 10/11

3. Теориялық бөлім

3.1 Шартты конструкциялар

1) if
if шарт:
    орындалатын код
2) if … else
if шарт:
    ...
else:
    ...
3) if … elif … else
if шарт1:
    ...
elif шарт2:
    ...
else:
    ...

3.2 Шарттарды құру

Салыстыру операторлары:

>, <, >=, <=, ==, !=

Логикалық операторлар:

and, or, not

4. Python мысалдары

Мысал 1. Санды тексеру

x = int(input("Сан енгізіңіз: "))

if x > 0:
    print("Позитив сан")
elif x < 0:
    print("Негатив сан")
else:
    print("Нөл")

Мысал 2. Жұп немесе тақ

n = int(input("Сан енгізіңіз: "))

if n % 2 == 0:
    print("Жұп сан")
else:
    print("Тақ сан")

Мысал 3. Баға қою

bal = int(input("Балл енгізіңіз: "))

if bal >= 90:
    print("A")
elif bal >= 75:
    print("B")
elif bal >= 60:
    print("C")
else:
    print("Өткен жоқ")

Мысал 4. Құрама шарт

age = int(input("Жасыңыз: "))

if age >= 18 and age <= 60:
    print("Жұмыс істеуге жарамды")
else:
    print("Жарамсыз")

5. Практикалық жұмыс қадамдары

1-қадам. Файл құру

Файл атауы: conditions.py

2-қадам. Қарапайым if іске қосу

Қолданушыдан сан енгізу → оң/теріс/нөл екенін анықтау.

3-қадам. elif конструкциясын қолдану

3–4 тармақты шарттармен есеп шығару.

4-қадам. Күрделі шарттарды біріктіру

and / or операторларын қолдану.

6. Практикалық тапсырмалар

Тапсырма 1. Санның таңбасын анықтау

Пайдаланушы сан енгізеді. Шығару:

  • Позитив
  • Негатив
  • Нөл

Тапсырма 2. Жұп немесе тақ

n % 2 == 0 шартын қолдану.

Тапсырма 3. Үш санның ең үлкенін табу

Пайдаланушы үш сан енгізеді.

Шарт арқылы ең үлкенін анықтаңыз.

Мысалы:

if a > b and a > c:

Тапсырма 4. Емтихан бағасы

0–100 аралығында балл енгізіледі.

Бағалау шкаласын шығару:

Балл Баға
90–100 A
75–89 B
60–74 C
50–59 D
< 50 F (өткен жоқ)

Тапсырма 5. Жыл басы немесе соңы

Ай нөмірін енгізіңіз (1–12).

Шығару:

Қыс
Көктем
Жаз
Күз

Тапсырма 6. Логин тексеру жүйесі

Қолданушы логин және пароль енгізеді.

login == "admin"
және 
password == "1234"
→ “Кіру сәтті өтті”

Басқа жағдайда → “Қате!”

Тапсырма 7. Температураны бағалау

Температура енгізіңіз. Шығару:

  • t < 0 → “Аяз”
  • 0–15 → “Салқын”
  • 16–30 → “Жылы”
  • 30 → “Ыстық”

Тапсырма 8. Жұмыс уақыты

Сағат енгізіңіз (0–23).

Шығару:

  • 9–18 → “Жұмыс уақыты”
  • Басқа уақыт → “Демалыс”

Тапсырма 9. Екі шартты біріктіру

Студенттің жасы және студент болуы:

age ≥ 18 and student == "yes"

Жауап: True/False

Тапсырма 10. Банк картасы тексеру

Жеке код енгізіледі.

Егер код 4 таңбалы сан болса → “Қабылданды”

Болмаса → “Қате!”

7. Қателер және оларды түзету

Қате Себебі Шешімі
IndentationError Шегініс дұрыс емес if-тен кейін 4 бос орын
ValueError Сан орнына мәтін енгізу int() қолданғанда сақ болу
SyntaxError Қате синтаксис : белгісін тексеру
Логикалық қате Шарт дұрыс құрылмаған and/or қолдануды тексеру

    1. if және elif айырмашылығы?

    3. Шартты жақшаға алу міндетті ме?

    4. Құрама шарт деген не?

    5. Екі немесе үш тармақты шартқа мысал келтіріңіз.
