ПРАКТИКАЛЫҚ ЖҰМЫС №11

Тақырыбы: Файлмен жұмыс тәжірибесі (File Handling)

1. Практикалық жұмыстың мақсаты

  • Python тілінде файлдарды ашу, оқу, жазу тәсілдерін меңгеру;
  • Файл режимдерін (r, w, a, x) қолдануды үйрену;
  • Файлдан жол-жолымен оқу, толық оқу, файлға қосып жазу дағдыларын қалыптастыру;
  • with open() конструкциясын дұрыс пайдалану;
  • Файлмен байланысты қателерді өңдеуді тәжірибеде қолдану.

2. Қажетті бағдарламалар

  • Python 3.10+
  • PyCharm / VS Code / Jupyter Notebook

3. Теориялық бөлім

3.1 Файл ашу синтаксисі

file = open("filename.txt", "mode")

Негізгі режимдер:

Режим Мағынасы
r оқу
w жазу (ескі файлды өшіреді)
a қосып жазу
x жаңа файл ғана жасау

3.2 Файлдан оқу тәсілдері

1) read() — толық оқу

text = file.read()

2) readline() — бір жол оқу

line = file.readline()

3) readlines() — барлық жолдарды тізім ретінде оқу 

lines = file.readlines()

3.3 Файлға жазу

file = open("data.txt", "w")
file.write("Hello!\n")
file.close()

3.4 with open() қолдану — қауіпсіз әдіс

with open("data.txt", "a") as f:
    f.write("New line\n")

Файл автоматты түрде жабылады.

3.5 Файл жоқ кезде қате өңдеу

try:
    f = open("abc.txt")
except FileNotFoundError:
    print("Файл табылмады!")

4. Практикалық жұмыс қадамдары

1-қадам. Файлға жазу

Файл: file_test.txt

with open("file_test.txt", "w") as f:
    f.write("Hello, students!\n")
    f.write("This is a file test.")

2-қадам. Файлдан оқу

with open("file_test.txt", "r") as f:
    print(f.read())

3-қадам. Файлға мәлімет қосу

with open("file_test.txt", "a") as f:
    f.write("\nNew line added.")

4-қадам. Жол-жолымен оқу

with open("file_test.txt", "r") as f:
    for line in f:
        print(line.strip())

5. Мысалдар

Мысал 1. Студенттер тізімін жазу

students = ["Aruzhan", "Dias", "Samat"]

with open("students.txt", "w") as f:
    for s in students:
        f.write(s + "\n")

Мысал 2. Файлды жолымен оқу

with open("students.txt", "r") as f:
    lines = f.readlines()
    print(lines)

Мысал 3. try–except арқылы қате өңдеу

try:
    with open("missing.txt", "r") as f:
        print(f.read())
except FileNotFoundError:
    print("Файл жоқ!")

Мысал 4. Жаңа файл жасау

with open("newfile.txt", "x") as f:
    f.write("Created new file.")

6. Практикалық тапсырмалар

Тапсырма 1. Өзіңіздің алғашқы мәтін файлыңызды құрыңыз

Файлға кемінде 3 сөйлем жазыңыз.

Тапсырма 2. Файлдан оқу

Жоғарыда жазған файлды оқып, жол-жолымен шығарыңыз.

Тапсырма 3. Файлға қосу

Сол файлға қосымша 2 сөйлем қосыңыз.

Тапсырма 4. Сандық мәліметтермен файл жасау

t.txt файлына 1–10 аралығындағы сандарды жол-жолымен жазыңыз.

Тапсырма 5. Файлдан сандарды оқып, олардың қосындысын табыңыз

Тапсырма 6. Қолданушы енгізген сөздерді файлға жазу

Қолданушы 5 сөз енгізеді → файлға сақталады.

Тапсырма 7. Файлдағы жол санын табу

Файлдан оқып, жол санын санаңыз.

Тапсырма 8. Файлдағы ең ұзын сөзді табу

Мәтіндік файлдан ең ұзын сөзді анықтаңыз.

Тапсырма 9. Екі файлды біріктіру

a.txt және b.txt файлдарының мазмұнын c.txt-ке көшіріңіз.

Тапсырма 10. Теріс сандарды анықтау

Файлдағы сандардан теріс сандарды бөліп көрсетіңіз.

7. Қателер және шешімдер

Қате Себебі Шешімі
FileNotFoundError Файл жоқ try–except немесе файл атауын тексеру
PermissionError Файлды ашуға рұқсат жоқ Файл орналасуын тексеру
Ескі деректер өшіп қалды w режимі қолданылды Қажет болса a режимін пайдалану
Файл жабылмау open() → close() ұмытылған with open() қолдану

8. Бақылау сұрақтары

    1. r, w, a режимдерінің айырмашылығы қандай?

    2. with open() қолданудың артықшылығы неде?

    3. read(), readline(), readlines() айырмашылығы?

    4. FileNotFoundError қандай жағдайда шығады?

    5. Жол-жолымен оқуды қалай жасаймыз?
