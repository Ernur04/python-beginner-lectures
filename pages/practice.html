ПРАКТИКАЛЫҚ ЖҰМЫС №1

Тақырыбы: Python орнату және алғашқы бағдарлама жазу

Әдістемелік нұсқау

1. Практикалық жұмыстың мақсаты

  • Студенттерге Python бағдарламалау тілін компьютерге орнатуды үйрету;
  • PyCharm немесе VS Code сияқты IDE орнату және бастапқы баптауды көрсету;
  • Алғашқы Python бағдарламасын жазу, іске қосу және қатесіз орындауға дағдыландыру;
  • Командалық жол (Terminal) арқылы Python жұмысын тексеру.

2. Қажетті бағдарламалар мен ресурстар

  • Python 3.10+ (ресми сайт: https://www.python.org/)
  • IDE:
    • PyCharm Community Edition
    • Visual Studio Code
  • Қарапайым мәтіндік редактор (Notepad, Sublime Text)
  • Операциялық жүйе: Windows 10/11

3. Теориялық бөлім (қысқаша)

3.1 Python деген не?

Python — жоғары деңгейлі, оқуға жеңіл, әмбебап бағдарламалау тілі.

Негізгі артықшылықтары:

  • жеңіл синтаксис;
  • көп кітапханалар;
  • веб, деректер ғылымы, AI, автоматтандыруда кең қолданыс.

3.2 Python орнату қадамдары

    1. https://www.python.org/→ Downloads → Python 3.x нұсқасын жүктеу.

    2. Орнату кезінде маңызды: ✔ Add Python to PATH — міндетті түрде белгілеу!

    3. Install Now → орнату аяқталған соң Close батырмасын басу.

3.3 Орнатуды тексеру

Командалық жолды (CMD / Terminal) ашып:

python --version

немесе

python

Жауап шықса, Python сәтті орнатылған.

4. IDE орнату және жоба құру

4.1 PyCharm Community Edition

    1. https://www.jetbrains.com/pycharm/download/?section=windows → Download

    2. Орнату → Community Edition

    3. PyCharm → New Project

    4. Project name: Python_Intro

    5. Interpreter: Python 3.x таңдаңыз

    6. Create

4.2 VS Code (балама нұсқа)

    1. VS Code жүктеу → орнату

    2. Extensions → Python модулін орнату

    3. File → New File → .py кеңейтуімен сақтау

5. Алғашқы бағдарлама

5.1 Код жазу

Жаңа файл ашыңыз → аты: hello.py

Код:

print("Hello, Python!")

5.2 Бағдарламаны іске қосу

  • PyCharm: Run → Run 'hello'
  • VS Code: Run → Run Python File
  • Терминалда:
python hello.py

Нәтижесі:

Hello, Python!

6. Қателер және оларды түзету

Қате түрі Себебі Шешімі
SyntaxError Жазылу қатесі Жақшалар, тырнақшаларды тексеру
NameError Атауы анықталмаған айнымалы Айнымалы атын дұрыс жазу
Python табылмады PATH қосылмаған Python-ды қайта орнату және PATH белгілеу

7. Практикалық тапсырмалар

Тапсырма 1. Python орнату

  • Python 3.x нұсқасын жүктеп орнатыңыз
  • CMD арқылы версиясын тексеріңіз
  • Скриншот жасаңыз

Тапсырма 2. Алғашқы бағдарлама

Келесі мәтінді шығарыңыз:

Мен Python тілін үйреніп жатырмын!

Тапсырма 3. Айнымалыларды пайдалану

Файлға төмендегі кодты жазыңыз:

name = "Indira"
age = 20
print("Атым:", name)
print("Жасым:", age)

Студент өз аты-жөнін енгізеді.

Тапсырма 4. Екі санды қосу

Пайдаланушыдан екі сан енгіздіріп, қосындысын шығаратын бағдарлама жазыңыз.

8. Бақылау сұрақтары

    1. Python тілінің негізгі артықшылықтары қандай?

    2. PATH деген не және неге ол маңызды?

    3. Терминалда Python версиясын қалай тексереміз?

    4. print() функциясының қызметі қандай?

    5. PyCharm IDE не үшін қолданылады?
