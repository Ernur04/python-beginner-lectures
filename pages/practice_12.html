ПРАКТИКАЛЫҚ ЖҰМЫС №12

Тақырыбы: Ерекшеліктерді өңдеу (Exception Handling: try/except)

1. Практикалық жұмыстың мақсаты

  • Python-дағы ерекшеліктер (exceptions) ұғымын түсіну;
  • Қателердің түрлерін тану және оларды өңдеу;
  • try, except, else, finally конструкцияларын қолдануды меңгеру;
  • Бағдарламаның бұзылмай жұмыс істеуін қамтамасыз ету;
  • Көп жағдайда туындайтын қателерді болжау және өңдеу тәжірибесін қалыптастыру.

2. Қажетті бағдарламалар

  • Python 3.10+
  • PyCharm / VS Code / Jupyter Notebook

3. Теориялық бөлім

3.1 Ерекшеліктер деген не?

Ерекшелік — бағдарлама орындалу кезінде туындайтын қате.

Мысалы:

x = int("abc")   # ValueError

Бағдарлама автоматты түрде тоқтап қалады.
Оны тоқтатпау үшін try/except қолданылады.

3.2 try/except негізгі құрылымы

try:
    # Қате болуы мүмкін код
except:
    # Қате болғанда орындалатын код

3.3 Белгілі қате түрін өңдеу

try:
    x = int(input("Сан енгіз: "))
except ValueError:
    print("Сан енгізу керек!")

3.4 Бірнеше except қолдану

try:
    f = open("data.txt")
    num = int("abc")
except FileNotFoundError:
    print("Файл табылмады!")
except ValueError:
    print("Сан дұрыс емес!")

3.5 else блогы

try:
    x = int(input("Сан: "))
except ValueError:
    print("Қате!")
else:
    print("Енгізілген сан:", x)

3.6 finally блогы

Қате болсын-болмасын міндетті түрде орындалады.

try:
    f = open("file.txt")
except:
    print("Қате!")
finally:
    print("Процесс аяқталды.")

4. Көп кездесетін қателер

Қате түрі Қай кезде шығады?
ValueError Сан емес мән енгізгенде
ZeroDivisionError 0-ге бөлу кезі
FileNotFoundError Файл табылмаған кезде
TypeError Қате типтермен операция жасағанда
IndexError Индекс диапазоннан тыс

5. Практикалық жұмыс қадамдары

1-қадам. Файл құру

Файл: exceptions.py

2-қадам. Қарапайым try/except

try:
    x = int(input("Сан енгіз: "))
    print("Сан:", x)
except ValueError:
    print("Сан енгізу керек!")

3-қадам. Бірнеше except тексеру

try:
    a = int(input("a: "))
    b = int(input("b: "))
    print(a / b)
except ZeroDivisionError:
    print("0-ге бөлуге болмайды!")
except ValueError:
    print("Сан енгізіңіз!")

4-қадам. finally қолдану

try:
    f = open("test.txt")
except FileNotFoundError:
    print("Файл жоқ!")
finally:
    print("Орындалды.")

6. Мысалдар

Мысал 1. Сан енгізу бақылауы

while True:
    try:
        n = int(input("Сан енгіз: "))
        break
    except ValueError:
        print("Қате! Тағы енгізіңіз.")

Мысал 2. Файл оқу

try:
    with open("data.txt") as f:
        print(f.read())
except FileNotFoundError:
    print("Файл табылмады!")

Мысал 3. Калькулятор (қате өңдеумен)

try:
    a = float(input("a: "))
    b = float(input("b: "))
    print("Нәтиже:", a / b)
except ZeroDivisionError:
    print("Нөлге бөлуге болмайды!")
except ValueError:
    print("Сандарды дұрыс енгізіңіз!")

7. Практикалық тапсырмалар

Тапсырма 1. Сан енгізуді қате өңдеу

Пайдаланушы сан емес нәрсе енгізсе → хабарлама шығару.

Тапсырма 2. 0-ге бөлуді өңдеу

Екі сан енгізіп, бөлуді орындаңыз.
Егер b = 0 болса → қате туралы хабарлама.

Тапсырма 3. Файл ашу

Файл жоқ болса "Файл табылмады" деп шығару.

Тапсырма 4. Индекс қатесін өңдеу

Тізім:

lst = [1, 2, 3]

Пайдаланушы индекс енгізеді. Индекс диапазоннан тыс болса → қате өңдеу.

Тапсырма 5. Қолданушы жасын тексеру

Пайдаланушы жасын енгізеді. Сан емес енгізсе → қайта сұрау.

Тапсырма 6. Калькулятор жазу

4 амал: +, -, *, /
Қате енгізсе → except арқылы өңдеу.

Тапсырма 7. Функция ішіндегі try/except

def to_int(x):
    return int(x)

Қате болса "Санға түрленбейді" деп қайтару.

Тапсырма 8. finally қолдану

Файл ашуға тырысып, соңында "Процесс аяқталды" деп шығару.

Тапсырма 9. Бірнеше except

Пайдаланушыдан енгізу → ValueError, TypeError, ZeroDivisionError қателерін бөлек өңдеу.

Тапсырма 10. Цикл ішінде қате өңдеу

Қолданушы теріс сан енгізгенше цикл жалғасады. Теріс сан енгізсе → ерекше хабарлама.

8. Қателер және шешімдер

Қате Себебі Шешімі
ValueError Сан емес енгізу except ValueError қолдану
ZeroDivisionError 0-ге бөлу бөлу алдында тексеру
FileNotFoundError Файл жоқ except арқылы өңдеу
IndexError Индекс диапазоннан тыс диапазон тексеру
TypeError Қате тип түрлендіру немесе тексеру

9. Бақылау сұрақтары

    1. try/except не үшін қолданылады?

    2. finally блогының қызметі?

    3. Көптеген except қолдануға бола ма?

    4. Қате өңделмесе не болады?

    5. try/except қолдану қай жерде қажет?
