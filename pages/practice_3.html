ПРАКТИКАЛЫҚ ЖҰМЫС №3

Тақырыбы: Арифметикалық және логикалық операциялар

1. Практикалық жұмыстың мақсаты

  • Python тіліндегі негізгі арифметикалық амалдарды үйрену;
  • Қалдықпен бөлу, дәрежелеу, бөлудің бүтін бөлігі сияқты операцияларды меңгеру;
  • Логикалық операцияларды (and, or, not) қолдана білу;
  • Салыстыру операторлары арқы (>, <, ==, !=, >=, <=) шарттарды құру;
  • Арифметикалық және логикалық өрнектерді біріктіріп қолдану дағдыларын дамыту.

2. Қажетті бағдарламалар

  • Python 3.10+
  • PyCharm / VS Code / Jupyter Notebook
  • Windows 10/11

3. Теориялық бөлім

3.1 Арифметикалық операциялар

Операция Белгісі Мысал Нәтиже
Қосу + 5 + 3 8
Азайту - 9 - 4 5
Көбейту * 6 * 2 12
Бөлу / 10 / 4 2.5
Бүтін Бөлу // 10 // 4 2
Қалдық % 10 % 4 2
Дәрежелеу ** 2 ** 3 8

Мысал:

a = 15
b = 4
print(a + b)
print(a - b)
print(a % b)
print(a // b)
print(a ** b)

3.2 Салыстыру операторлары

Белгі Мағынасы Мысал Нәтиже
== тең бе? 5 == 5 True
!= тең емес пе? 5 != 3 True
> үлкен 7 > 4 True
< кіші 2 < 9 True
>= үлкен/тең 4 >= 4 True
<= кіші/тең 3 <= 2 False

Мысал:

x = 10
print(x > 5)
print(x == 10)

3.3 Логикалық операциялар

Операция Жұмысы Мысал Нәтиже
and екі шарт та True болса True and False False
or біреуі True болса жеткілікті True or False True
not мәнді терістейді not True False

Мысал:

age = 18
is_student = True
print(age >= 18 and is_student)   # True
print(age >= 18 or is_student)    # True
print(not is_student)             # False

3.4 Арифметикалық және логикалық өрнекті біріктіру

a = 10
b = 3
result = (a % b == 1) and (a > b)
print(result)

4. Практикалық жұмыс қадамдары

4.1 Жаңа Python файлын ашу

Файл атауы: operators.py

4.2 Арифметикалық амалдарды тексеру

a = int(input("a санын енгізіңіз: "))
b = int(input("b санын енгізіңіз: "))

print("Қосу:", a + b)
print("Азайту:", a - b)
print("Көбейту:", a * b)
print("Бөлу:", a / b)
print("Бүтін бөлу:", a // b)
print("Қалдық:", a % b)
print("Дәрежелеу:", a ** b)

4.3 Салыстыру операторларын тексеру

x = int(input("x санын енгізіңіз: "))

print(x > 10)
print(x <= 5)
print(x == 7)

4.4 Логикалық операторлар мысалы

age = int(input("Жасыңызды енгізіңіз: "))
student = input("Студентсіз бе? (иә/жоқ): ")

is_student = (student == "иә")

print(age >= 18 and is_student)
print(age < 18 or is_student)
print(not is_student)

5. Қателер және шешімдер

Қате Себебі Шешімі

6. Практикалық тапсырмалар

Тапсырма 1. Арифметикалық амалдар

Қолданушыдан екі сан енгіздіріп, барлық төмендегі операцияларды шығарыңыз:

  • қосу
  • азайту
  • көбейту
  • бөлу
  • қалдық табу
  • бүтін бөлу
  • дәрежелеу

Тапсырма 2. Салыстыру операторлары

Қолданушы енгізген сан бойынша:

  • сан 10-нан үлкен бе?
  • 5-ке тең немесе кіші ме?
  • 2-ге қалдықсыз бөлінеді ме?

Тапсырма 3. Логикалық өрнектер

Пайдаланушыдан:

  • жасы
  • “студентсіз бе?” деген сұрақ

алып, төмендегіні анықтаңыз:

(Жасы 18-ден үлкен И студент) → True/False
(Жасы 18-ден кіші НЕМЕСЕ студент) → True/False
Студент еместігін анықтау → True/False

Тапсырма 4. Композициялық есеп

Үш сан берілсін: a, b, c.

Шартты тексеріңіз:

a > b and b > c

Жауапты True/False етіп шығарыңыз.

Тапсырма 5. Қалдықпен бөлу логикасы

Пайдаланушыдан сан енгізіңіз.

Санның жұп не тақ екенін анықтаңыз:

e = int(input("Сан: "))
print(e % 2 == 0)

Тапсырма 6. Шарттарды біріктіру

Студенттің балы (0–100).

Ол "өткен" немесе "өткен жоқ" екенін анықтаңыз:

passed = (бал >= 50 and бал <= 100)
