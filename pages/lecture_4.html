4 лекция. Шартты операторлар (if, elif, else)

📌 Сурет 1. Шартты операторлар құрылымы (орынбасар сурет).

1. Шартты оператор дегеніміз не?

Шартты оператор — белгілі бір шарттың True немесе False болуына байланысты әртүрлі әрекеттерді орындауға мүмкіндік береді.

2. if операторы

Құрылымы:

  • if шарт:
    әрекет

Мысал:

age = 18
if age >= 18:
    print('Сіз ересексіз.')

3. if…else операторы

Құрылымы Мысалы 
if шарт: әрекет1
else: әрекет2
 
number = 5
if number % 2 == 0:
    print("Жұп")
else:
    print("Тақ")

4. elif операторы

Бірнеше шартты тізбектей тексеру үшін қолданылады.

if шарт1: әрекет1
elif шарт2: әрекет2
else: әрекет

5. Логикалық операторлар

Оператор Мағынасы
and Екі шарт та True болса
or Кемінде бір шарт True болса
not Терістеу

6. Ішкі шарттар (nested if)

if жасырын түрде басқа if ішінде қолданылуы мүмкін.

Мысал:

age = 25
is_student = True
if age > 18:
    if is_student:
        print('Студенттерге жеңілдік бар')
    else:
        print('Жеңілдік тек студенттерге')

7. Тернарлық оператор

Қысқа шарт жазуға арналған нұсқа:
result = 'Жұп' if x % 2 == 0 else 'Тақ'
