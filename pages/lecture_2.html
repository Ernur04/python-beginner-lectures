Лекции по Python

Изучайте Python шаг за шагом: от основ до профессионального уровня.

2 лекция. Айнымалылар және деректер типтері

1. Айнымалы дегеніміз не?

Айнымалы — белгілі бір мәнді уақытша жадыда сақтайтын контейнер. Python айнымалыны автоматты түрде жасайды.

Мысал:

x = 10
name = "Indira"
price = 99.5

2. Айнымалы атауына қойылатын талаптар

Рұқсат етіледі: әріптер, сандар (бірінші емес), төменгі сызықша.

Рұқсат етілмейді: бос орын, арнайы символдар, санмен бастау.

Дұрыс: student_name, age

Қате: 1age, student-name

3. Айнымалының типінің автоматты анықталуы

Python мәнге қарап типті автоматты анықтайды:

x = 5
y = 3.14
name = "Aida"

4. Негізгі деректер типтері

  • int — бүтін сандар
  • float — ондық сандар
  • str — мәтін
  • bool — True/False
  • list — тізім
  • tuple — кортеж
  • set — жиын
  • dict — сөздік

5. type() функциясы

Айнымалының типін анықтау үшін:

x = 10
print(type(x))

6. Арифметикалық операциялар

  • a + b — қосу
  • a - b — азайту
  • a * b — көбейту
  • a / b — бөлу
  • a // b — бүтін бөлу
  • a % b — қалдық
  • a ** b — дәреже

7. Айнымалыны қайта меншіктеу

x = 10
x = "Hello"   # тип автоматты түрде өзгереді

8. Бір қатарда бірнеше айнымалы жазу

a = b = c = 10
x, y, z = 5, 10, 15

9. input() арқылы енгізу

name = input("Атыңыз: ")
age = int(input("Жасыңыз: "))

10. Практикалық тапсырмалар

  • 3 айнымалы құрып, типін шығару.
  • Пайдаланушыдан 3 сан алып, қосындысын шығару.
  • Студент туралы dict құру.
  • Тізімнен ең кішісі мен үлкенін табу.
  • Айнымалы типін өзгерту (int → str → float).

Қорытынды

Бұл тақырыпта айнымалылар, деректер типтері, операциялар, type(), input() қолдану үйретілді.
