ПРАКТИКАЛЫҚ ЖҰМЫС №2

Тақырыбы: Айнымалылар және енгізу/шығару операциялары (input/output)

1. Практикалық жұмыстың мақсаты

  • Python тілінде айнымалы ұғымын түсіну;
  • Айнымалыларды әртүрлі типтермен (int, float, str) құру және пайдалану;
  • input() функциясы арқылы қолданушыдан мәлімет енгізу;
  • print() көмегімен нәтижені экранға шығару;
  • Конвертация (түр өзгерту) амалдарын қолдану: int(), float(), str().

2. Қажетті бағдарламалар

  • Python 3.10+
  • PyCharm, VS Code немесе Jupyter Notebook
  • Операциялық жүйе: Windows 10/11

3. Теориялық бөлім (қысқаша)

3.1 Айнымалы деген не?

Айнымалы — деректерді сақтауға арналған атауы бар жады аймағы.

Мысал:

age = 18
name = "Aigerim"
price = 45.6

Python автоматты түрде типін анықтайды.

3.2 Айнымалылар типтері

Тип Мысал Түсініктеме
int 5, -2 бүтін сан
float 3.14 нақты сан
str "Hello" мәтін
bool True, False логикалық

3.3 Енгізу (input)

input() — қолданушыдан дерек енгізуге арналған функция. 

name = input("Атыңызды енгізіңіз: ")

3.4 Шығару (print)

print() — экранға ақпарат шығару.

print("Сәлем,", name)

3.5 Түр өзгерту (type casting)

a = int(input("Бірінші сан: "))
b = float(input("Екінші сан: "))

4. Практикалық қадамдар

4.1 Жаңа жоба ашу

PyCharm → New Project → Create

Файл: variables.py

4.2 Қарапайым айнымалылармен жұмыс

Мысал:

city = "Taraz"
year = 2025
temperature = 12.5

print(city)
print(year)
print(temperature)

4.3 Енгізу/шығару мысалы

name = input("Атыңыз: ")
age = input("Жасыңыз: ")

print("Сізді көргеніме қуаныштымын,", name)
print("Жасыңыз:", age)

4.4 Түр өзгерту мысалы

a = int(input("Бірінші санды енгізіңіз: "))
b = int(input("Екінші санды енгізіңіз: "))

total = a + b
print("Қосынды:", total)
