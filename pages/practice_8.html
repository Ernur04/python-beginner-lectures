ПРАКТИКАЛЫҚ ЖҰМЫС №8

Тақырыбы: Сөздіктер құру және өңдеу (Dictionary)

1. Практикалық жұмыстың мақсаты

  • Python тілінде сөздік (dict) құрылымын түсіну;
  • Кілт–мән (key–value) жұптарымен жұмыс істеу;
  • Сөздікке элемент қосу, жою, өзгерту;
  • Сөздіктен мән алу, кілт арқылы іздеу;
  • Сөздіктерді өңдеу арқылы практикалық есептер шығару.

2. Қажетті бағдарламалар

  • Python 3.10+
  • PyCharm / VS Code / Jupyter Notebook

3. Теориялық бөлім

3.1 Сөздік (dict) деген не?

Сөздік — мәліметтерді кілт–мән түрінде сақтайтын құрылым.

student = {
    "name": "Aruzhan",
    "age": 18,
    "city": "Taraz"
}

Сөздік қасиеттері:

  • кілттер қайталанбайды;
  • мәндер кез келген типте болуы мүмкін;
  • элементтерге индекспен емес, кілт арқылы қол жеткізіледі.

3.2 Сөздіктен мән алу

print(student["name"])

Қате шығармай алу:

print(student.get("age"))

3.3 Элемент қосу және өзгерту

1) Жаңа кілт қосу

student["grade"] = "A"

2) Бар мәнді өзгерту

student["age"] = 19

3.4 Элемент жою

1) pop()

student.pop("city")

2) del

del student["age"]

3) clear()

student.clear()

3.5 Сөздік әдістері

Әдіс Мысал Түсініктеме
keys() d.keys() Кілттер
values() d.values() Мәндер
items() d.items() Кілт–мән жұптары
update() d.update({"age": 20}) Бірнеше элементті өзгерту

4. Практикалық жұмыс қадамдары

1-қадам. Файл құру

Файл атауы: dicts.py

2-қадам. Қарапайым сөздік құру

car = {
    "model": "Toyota",
    "year": 2020,
    "color": "white"
}

3-қадам. Мәнді оқу

print(car["model"])
print(car.get("color"))

4-қадам. Жаңа кілт қосу

car["price"] = 12000

5-қадам. Кілтті өзгерту

car["color"] = "black"

6-қадам. Жою операциялары

car.pop("year")
del car["model"]

5. Мысалдар

Мысал 1. Қолданушы мәліметтері

person = {}
person["name"] = input("Атыңыз: ")
person["age"] = int(input("Жасыңыз: "))
print(person)

Мысал 2. Барлық кілттер мен мәндерді шығару

for k, v in person.items():
    print(k, ":", v)

Мысал 3. Сөздік жаңарту

student.update({"gpa": 3.9, "year": 2})

6. Практикалық тапсырмалар

Тапсырма 1. Сөздік құру

Студент туралы сөздік жасаңыз:

student = {
    "name": "...",
    "age": ...,
    "major": "Informatics"
}

Жеке-жеке шығарыңыз.

Тапсырма 2. Кілт қосу және өзгерту

Алдыңғы сөздікке:

  • "grade" → мән "A"
  • "age" → жаңа мән

Тапсырма 3. Кілт жою

Сөздіктен "major" кілтін жойыңыз.

Тапсырма 4. Кітапхана сөздігі

book = {
    "title": "Python",
    "author": "Guido",
    "year": 1991
}

Тапсырама:

  • "pages" кілтін қосу
  • "year" мәнін өзгерту
  • Барлық кілт–мәндерді шығару

Тапсырма 5. Қолданушы енгізетін сөздік

Пайдаланушы 3 пән және олардың бағаларын енгізеді.
Сөздікке сақтаңыз.

Мысалы:

math: 95
physics: 88
ict: 90

Тапсырма 6. Ең жоғары бағаны табу

5-пәндік сөздіктен ең жоғары бағаны анықтаңыз.

Тапсырма 7. Кілт арқылы іздеу

Қолданушы пән атын енгізеді.
Сөздікте бар болса → бағасын көрсетіңіз.
Жоқ болса → "Мұндай пән жоқ".

Тапсырма 8. Автокөлік базасы

Кемінде 3 авто туралы сөздік тізімі:

cars = [
    {"model": "Toyota", "year": 2020},
    {"model": "BMW", "year": 2018},
    {"model": "Hyundai", "year": 2021}
]

Тапсырма:

  • барлық модельдерді шығару
  • ең жаңа автоны табу

Тапсырма 9. Статистика құру

Тізім:

nums = [1,2,3,3,4,5,5,5]

Әр сан қанша рет кездесетінін сөздік түрінде шығару.

Нәтиже:

{1:1, 2:1, 3:2, 4:1, 5:3}

Тапсырма 10. Қос сөздікпен жұмыс

Екі сөздікті біріктіріңіз:

a = {"x": 1, "y": 2}
b = {"y": 3, "z": 4}

Нәтиже:

{"x":1, "y":3, "z":4}

update() қолдану

7. Қателер және шешімдер

Қате Себебі Шешімі
KeyError Жоқ кілтке жүгіну get() қолдану
TypeError: unhashable type Кілтке list сияқты өзгермелі тип қолдану тек str, int сияқты hashable кілт қолдану
Сөздік тазаланып кету clear() қолданылған Қажет кезде ғана қолдану

    3. pop() және del айырмашылығы?

    4. keys(), values(), items() не үшін керек?

    5. dict.get() қандай жағдайда қолданылады?
