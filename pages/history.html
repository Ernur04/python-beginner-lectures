Краткая история языка Python

1980-е: Идея и начало

Python был задуман в конце 1980-х годов Гвидо ван Россумом (Guido van Rossum) в качестве преемника языка ABC, который был способен обрабатывать исключения и взаимодействовать с операционной системой Amoeba.

Декабрь 1989

1991: Рождение Python 0.9.0

Гвидо публикует первую версию кода — Python 0.9.0. В ней уже присутствовали классы с наследованием, обработка исключений, функции и основные типы данных: списки, словари и строки.

Февраль 1991

2000: Python 2.0

В Python 2.0 появились важные функции, такие как сборка мусора (garbage collection) и поддержка Unicode. Это значительно повысило его популярность, особенно в академических кругах и стартапах.

Октябрь 2000

2008: Python 3.0 (Python 3000)

Выходит Python 3.0, который был радикальным изменением. Он устранил многие недостатки дизайна и синтаксиса, но был несовместим с версией 2.x, что вызвало долгий переходный период. Ключевое изменение — функция print стала оператором print().

Декабрь 2008

2020: Окончание поддержки Python 2

Официальная поддержка Python 2.7 была окончательно прекращена, что побудило большинство разработчиков перейти на Python 3. С тех пор Python 3 является единственной поддерживаемой версией.

Январь 2020

Влияние и будущее

Python продолжает развиваться под руководством сообщества. Сегодня он доминирует в таких областях, как машинное обучение (TensorFlow, PyTorch) и наука о данных (Pandas, NumPy), а также остается одним из самых популярных языков для веб-разработки (Django, Flask).
