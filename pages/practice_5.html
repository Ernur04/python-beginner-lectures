ПРАКТИКАЛЫҚ ЖҰМЫС №5

Тақырыбы: Циклдер қолдану (for, while)

1. Практикалық жұмыстың мақсаты

  • Python тілінде циклдердің жұмыс принципін түсіну;
  • for және while циклдерін есеп шығару кезінде қолдану;
  • Диапазонмен жұмыс (range()) жүргізу;
  • Итерация, қайталану саны және тоқтату шарты туралы түсінік қалыптастыру;
  • Циклдерді шартты конструкциялармен біріктіре есеп шығару дағдысын дамыту.

2. Қажетті бағдарламалар

  • Python 3.10+
  • PyCharm / VS Code / Jupyter Notebook
  • Windows 10/11

3. Теориялық бөлім

3.1 for циклі

for циклі белгілі бір тізімдегі немесе диапазондағы элементтерді рет-ретімен өңдеу үшін қолданылады.

Мысал:

for i in range(5):
    print(i)

Нәтиже: 

0 1 2 3 4

range() функциясы

Пішім Мысалы Нәтиже
range(n) range(5) 0–4
range(a, b) range(2, 7) 2–6

3.2 while циклі

while циклі шарт True болғанша қайталанады.

i = 1
while i <= 5:
    print(i)
    i += 1

3.3 break және continue

break

Циклді толық тоқтатады.

for i in range(10):
    if i == 5:
        break

continue

Ағымдағы итерацияны өткізіп, циклды жалғастырады.

for i in range(10):
    if i % 2 == 0:
        continue
    print(i)

4. Практикалық жұмыс қадамдары

1-қадам. Файл құру

Файл атауы: loops.py

2-қадам. Қарапайым for циклін орындау

0–10 аралығындағы сандарды шығару.

3-қадам. while циклін қолдану

Қолданушы енгізген саннан бастап 1-ге дейін кері санау.

4-қадам. break / continue операторларын тексеру

5. Python мысалдары

Мысал 1. 1-ден 10-ға дейін шығару

for i in range(1, 11):
    print(i)

Мысал 2. Кері санау

i = 10
while i >= 1:
    print(i)
    i -= 1

Мысал 3. Тек жұп сандар

for i in range(1, 21):
    if i % 2 != 0:
        continue
    print(i)

Мысал 4. break қолдану

for i in range(100):
    if i == 10:
        break
    print(i)

6. Практикалық тапсырмалар

Тапсырма 1. 1–20 аралығындағы сандарды шығару

for циклімен 1-ден 20-ға дейінгі сандарды шығарыңыз.

Тапсырма 2. Жұп сандар

1–50 аралығындағы жұп сандарды басып шығарыңыз.

Тапсырма 3. Тақ сандардың қосындысы

1–100 аралығындағы тақ сандардың қосындысын табыңыз.

Тапсырма 4. while циклымен кері санау

Пайдаланушы сан енгізеді. Содан кейін цикл арқылы 1-ге дейін кері санаңыз.

Тапсырма 5. Кесте (көбейту кестесі)

Қолданушы сан енгізеді. Сол санның көбейту кестесін шығару:

5 x 1 = 5
5 x 2 = 10
...

Тапсырма 6. break қолдану

Пайдаланушы теріс сан енгізгенше сандарды сұрап тұрыңыз.

Тапсырма 7. Санның цифрларын санау

Мысалы, 12345 → 5 цифр. Циклмен анықтаңыз.

Тапсырма 8. Факториал есептеу

Қолданушы сан енгізеді және оның факториалын табыңыз.

Тапсырма 9. Екі сан аралығындағы сандар

Пайдаланушы a және b санын енгізеді.
Цикл арқылы барлық сандарды шығарыңыз.

Тапсырма 10. Негатив санға дейін қосынды

Пайдаланушы бірнеше сан енгізеді.
Егер теріс сан енгізілсе → цикл тоқтайды.
Осы уақытқа дейін енгізілген сандардың қосындысын шығару.

7. Қателер және шешімдер

Қате Себебі Шешімі
Шексіз цикл while шарт өзгермейді Айнымалыны жаңарту (i += 1)
ValueError мәтінді санға түрлендіре алмау int() қолданғанда абай болу
IndentationError шегініс қате 4 бос орын пайдалану
Логикалық қате break/continue дұрыс емес жерге қойылған шартыңызды тексеру
