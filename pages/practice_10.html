ПРАКТИКАЛЫҚ ЖҰМЫС №10

Тақырыбы: Модульдер мен кітапханаларды қолдану (import, Python libraries)

1. Практикалық жұмыстың мақсаты

  • Python тілінде модуль (module) ұғымын түсіну;
  • Стандартты кітапханаларды (math, random, datetime, т.б.) қолдануды үйрену;
  • Өз модулін құру және импорттау;
  • Модульдегі функцияларды шақыру және қайта пайдалану;
  • Практикалық есептерді кітапхана мүмкіндіктерімен тиімді шығару дағдысын қалыптастыру.

2. Қажетті бағдарламалар

  • Python 3.10+
  • PyCharm / VS Code / Jupyter Notebook

3. Теориялық бөлім

3.1 Модуль деген не?

Модуль — Python кодтары жазылған жеке файл. Оны басқа файлға импорттап, оның ішіндегі функциялар мен айнымалыларды қолдануға болады.

Импорттау синтаксисі:

import module_name

Немесе:

from module_name import function_name

3.2 Стандартты кітапханаларды қолдану

1) math модулі

Көптеген математикалық функциялар енгізілген.

import math

print(math.sqrt(16))     # түбір
print(math.pow(2, 3))    # дәреже
print(math.sin(math.pi)) # синус

2) random модулі

Кездейсоқ сандар генерациясы.

import random

print(random.randint(1, 10))  # 1–10 аралығында кездейсоқ сан
print(random.choice(["red", "blue", "green"]))  # тізімнен таңдау

3) datetime модулі

Уақыт және дата.

from datetime import datetime

now = datetime.now()
print(now)
print(now.year, now.month, now.day)

4) time модулі

import time

print("Start")
time.sleep(2)  # 2 секунд күту
print("End")

3.3 Өз модуліңді құру

1-қадам. Файл құру

Файл: my_module.py

def hello():
    print("Hello from my module!")

def add(a, b):
    return a + b

2-қадам. Басқа файлда импорттау

Файл: main.py

import my_module

my_module.hello()
print(my_module.add(5, 7))

4. Практикалық жұмыс қадамдары

1-қадам. Файл құру

Файл: modules.py

2-қадам. math модулін қолдану

Пайдаланушы сан енгізеді → квадрат түбірі мен дәрежесін шығару.

3-қадам. random модулін қолдану

1–50 аралығында кездейсоқ сан шығару.

4-қадам. datetime модулін тексеру

Ағымдағы уақытты форматтап көрсету:

now.strftime("%H:%M:%S")

5-қадам. Өз модулін импорттау

5. Мысалдар

Мысал 1. Кездейсоқ сандар

for i in range(5):
    print(random.randint(1, 100))

Мысал 2. Үшбұрыш гипотенузасы

import math

a, b = 3, 4
c = math.sqrt(a*a + b*b)
print(c)

Мысал 3. Дата форматтау

from datetime import datetime

now = datetime.now()
print(now.strftime("Today: %d.%m.%Y"))

Мысал 4. Өз модулің

my_module.py:

def multiply(a, b):
    return a * b

main.py:

from my_module import multiply
print(multiply(4, 5))

6. Практикалық тапсырмалар

Тапсырма 1. math модулі

Пайдаланушыдан сан енгізіңіз және табыңыз:

  • квадрат түбірі
  • квадратқа шығару
  • синус/косинус

Тапсырма 2. random модулі

Кездейсоқ:

  • 1–100 аралығында сан
  • Тізімнен кездейсоқ сөз таңдау
  • Кездейсоқ пароль генерациялау (5 символ)

Тапсырма 3. datetime модулі

Шығарыңыз:

  • ағымдағы жыл
  • ай
  • уақыт (сағат:минут:секунд)

Тапсырма 4. time.sleep()

Бағдарлама 3 секунд күтсін, содан кейін:

Сәлем студент!

Тапсырма 5. Өз модулін құру

Функциялар:

  • hello()
  • square(x)
  • calc(a, b, op)

Басқа файлдан импорттап қолданыңыз.

Тапсырма 6. Кездейсоқ тізім

5 кездейсоқ саннан тұратын тізім құрыңыз.

Тапсырма 7. Кездейсоқ логин генераторы

random.choice() арқылы 6 символдан тұратын логин жасаңыз.

Тапсырма 8. Секундты күн/сағатқа айналдыру

Datetime қолданбай есептеңіз.

Тапсырма 9. “Қазіргі жас” функциясы

Пайдаланушы туған жылын енгізеді → жасын есептеу.

Тапсырма 10. Модульдерді біріктіре қолдану

random, math, datetime қолданып шағын бағдарлама жасаңыз.

7. Қателер және шешімдер

Қате Себебі Шешімі
ModuleNotFoundError Модуль атауы қате Файл атын тексеру
ImportError Модуль ішіндегі функция жоқ Атауды тексеру
NameError Функцияға дұрыс сілтеме жасалмаған module.function пішімі
Путь табылмайды Файл дұрыс папкада емес Бір папкада болсын

    4. Өз модуліңді қалай жасайсың?
