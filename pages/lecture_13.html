13 лекция. Python-дағы объектіге бағытталған программалау (OOP) негіздері

1. OOP дегеніміз не?

Объектіге бағытталған программалау (Object-Oriented Programming — OOP) — бағдарламаны объектілер мен кластар арқылы құру тәсілі. OOP программаның құрылымын тиімді ұйымдастыруға, кодты қайта қолдануға мүмкіндік береді.

2. Негізгі ұғымдар

Ұғым Түсіндірме
Класс (class) Объект жасауға арналған қалып (шаблон)
Объект (object) Кластан жасалған нақты экземпляр
Қасиеттер (attributes) Объектінің мәліметтері/мәлімет өрістері
Әдістер (methods) Объект орындайтын функциялар

3. Класс пен объект байланысы (диаграмма орны)

4. Python-дағы класс анықтамасы

Python-да класс def емес, class кілт сөзі арқылы анықталады.

class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def info(self):
        print(self.name, self.age)

5. Объект жасау

s1 = Student('Aida', 18)
s1.info()

6. __init__ әдісі

__init__ — объект пайда болған кезде автоматты түрде жұмыс істейтін арнайы конструктор әдісі.

7. Әдістер (methods)

  • Объект ішіндегі функциялар әдістер деп аталады.
  • Әр әдіс self параметрі арқылы объектімен байланысты.
  • self — объектінің өзін білдіреді.

8. Инкапсуляция

Инкапсуляция — объект ішіндегі мәліметтерді қорғау және жасырын ету принципі.

9. Мұрагерлік (inheritance)

Мұрагерлік арқылы бір класс басқа кластың қасиеттерін алады.

class Animal:
    def sound(self):
        print('Animal sound')

class Dog(Animal):
    def sound(self):
        print('Woof!')

10. Полиморфизм (polymorphism)

Полиморфизм — бірдей аталған әдістердің әр объект үшін әртүрлі жұмыс істеуі.

11. Практикалық тапсырмалар

    Student класы: name, age, gpa қасиеттері бар класс жазу.

    Worker класы: жалақы есептейтін әдісі болсын.

    Animal → Dog, Cat мұрагерлік мысалын жазу.

    Полиморфизм мысалы: speak() әдісі әр жануарда әртүрлі болсын.

    Көп объект жасап, олардың қасиеттерін шақыру.
