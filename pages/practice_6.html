ПРАКТИКАЛЫҚ ЖҰМЫС №6

Тақырыбы: Тізімдермен жұмыс — элемент қосу, жою, іздеу

1. Практикалық жұмыстың мақсаты

  • Python тілінде list (тізім) құрылымын түсіну;
  • Тізімге жаңа элементтерді қоса білу (append, insert, extend);
  • Тізімнен элементтерді жою (remove, pop, del);
  • Тізім ішінде элементті іздеу (in, index, count);
  • Тізімдермен алгоритмдік есептер шығару дағдысын қалыптастыру.

2. Қажетті бағдарламалар

  • Python 3.10+
  • PyCharm / VS Code / Jupyter Notebook

3. Теориялық бөлім

3.1 Тізім (list) деген не?

Тізім — бірнеше мәндерді бір айнымалыда сақтауға мүмкіндік беретін құрылым.

students = ["Aruzhan", "Dias", "Nursultan"]

3.2 Элемент қосу тәсілдері

1) append() — соңына қосу

numbers = [1, 2, 3]
numbers.append(4)

2) insert() — белгілі орынға қосу

numbers.insert(1, 100)

3) extend() — басқа тізім қосу

a = [1, 2]
b = [3, 4]
a.extend(b)

3.3 Элемент жою тәсілдері

1) remove() — мәні бойынша жою

fruits.remove("apple")

2) pop() — индекс бойынша жою

fruits.pop(2)

3) del — индексті немесе бөлікті жою

del fruits[0]

4) clear() — толық тазарту

fruits.clear()

3.4 Элемент іздеу

1) in — бар-жоғын тексеру

print("apple" in fruits)

2) index() — индексін табу

fruits.index("banana")

3) count() — қанша рет кездеседі

numbers.count(5)

4. Практикалық жұмыс қадамдары

1-қадам. Жаңа файл құру

Файл атауы: lists.py

2-қадам. Тізім құру

Студенттердің тізімін жасаңыз:

students = ["Aruzhan", "Dias", "Dana"]

3-қадам. Қосу әдістерін қолдану

students.insert(1, "Samat")
students.append("Alikhan")

4-қадам. Жою әдістерін тексеру

students.remove("Dana")
students.pop(2)

5-қадам. Іздеу әдістерін қолдану

print("Dias" in students)
print(students.index("Aruzhan"))

5. Python мысалдары

Мысал 1. Қарапайым тізім

numbers = [10, 20, 30]
numbers.append(40)
print(numbers)

Мысал 2. Элементті жою

colors = ["red", "green", "blue"]
colors.remove("green")
print(colors)

Мысал 3. Іздеу

fruits = ["apple", "banana", "apple", "orange"]
print(fruits.count("apple"))
print("orange" in fruits)

6. Практикалық тапсырмалар

Тапсырма 1. Тізімге элемент қосу

Бастапқы тізім:

cities = ["Taraz", "Astana", "Almaty"]

Қосыңыз:

  • "Shymkent" — соңына
  • "Oskemen" — 1-индекске

Тапсырма 2. Элемент жою

Тізімнен "Astana" сөзін өшіріңіз. Соңғы элементті pop() арқылы алып тастаңыз.

Тапсырма 3. Іздеу операциялары

Тізім:

nums = [1, 3, 5, 7, 5, 9, 5]

Тапсырамалар:

  • 5 саны неше рет кездеседі (count)
  • Тізімде 7 саны бар ма (in)
  • 5 санының алғашқы индексі (index)

Тапсырма 4. Тізімді толық тазалау

t.clear() әдісін қолданыңыз.

Тапсырма 5. Қолданушыдан тізім құру

Қолданушыдан 5 элемент енгіздіріп, тізімге қосыңыз.

Тапсырма 6. Екі тізімді біріктіру

a = [1, 2, 3]
b = [4, 5, 6]

extend() әдісімен біріктіріңіз.

Тапсырма 7. Студент іздеу

Студенттің атын енгізіңіз.
Егер тізімде бар болса → “Табылды”.
Жоқ болса → “Тізімде жоқ”.

Тапсырма 8. Ең үлкен және ең кіші элемент

Тізімдегі ең үлкен және ең кіші элементті шығарыңыз.

Тапсырма 9. Белгілі диапазонды жою (del)

Тізімнен 2–4 индекстер аралығын жойыңыз.

Тапсырма 10. Сұрыптау

Тізімді өсу ретімен және кему ретімен сұрыптаңыз:

list.sort()
list.sort(reverse=True)

7. Қателер және шешімдер

Қате Себебі Шешімі
ValueError: list.remove(x) Тізімде жоқ элементті жою Жою алдында in тексеру
IndexError Қате индекс Индексті тексеру
TypeError Түрлер сәйкес емес Тізім элементтерін бірдей типте сақтау
Тізім тазалап кеткен clear() қолданылған Нұсқаулықсыз орындамау

8. Бақылау сұрақтары

    1. append() мен insert() айырмашылығы?

    2. remove() мен pop() айырмашылығы?

    3. in операторы не үшін қажет?

    4. extend() не істейді?

    5. index() қандай жағдайда қате шығарады?
