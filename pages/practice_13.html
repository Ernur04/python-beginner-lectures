ПРАКТИКАЛЫҚ ЖҰМЫС №13

Тақырыбы: Класс пен объект құру (Object-Oriented Programming: Class & Object)

1. Практикалық жұмыстың мақсаты

  • Python тілінде класс ұғымын түсіну;
  • Объект (instance) құру және қолдану;
  • __init__() инициализация әдісінің жұмыс логикасын меңгеру;
  • Класс ішіндегі атрибуттар (properties) және әдістер (methods) жазу;
  • Бірнеше объект құрып, олармен түрлі операциялар орындау.

2. Қажетті бағдарламалар

  • Python 3.10+
  • PyCharm / VS Code / Jupyter Notebook

3. Теориялық бөлім

3.1 Класс деген не?

Класс — объектілерді құруға арналған үлгі (шаблон).

class Student:
    pass

3.2 Объект деген не?

Объект — кластан жасалған нақты экземпляр (instance).

s1 = Student()

3.3 Атрибуттар және әдістер

Атрибут (property) — объект мәліметі
Әдіс (method) — объект орындайтын әрекет

3.4 Инициализация әдісі __init__()

class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

self — объектінің өзі.

3.5 Класс әдісі

def info(self):
    return f"{self.name}, {self.age} жаста"

4. Класс құрудың толық мысалы

class Student:
    def __init__(self, name, age, major):
        self.name = name
        self.age = age
        self.major = major
    
    def info(self):
        return f"{self.name}, {self.age} жаста, мамандығы: {self.major}"

Объект құру:

s = Student("Aruzhan", 18, "IT")
print(s.info())

5. Практикалық жұмыс қадамдары

1-қадам. Файл құру

Файл атауы: class_object.py

2-қадам. Қарапайым класс жазу

class Person:
    pass

3-қадам. Атрибут қосу (қолмен)

p = Person()
p.name = "Dana"
p.age = 20

4-қадам. init() қолданып жазу

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

5-қадам. Әдіс жазу

def show(self):
    print(f"{self.name}, {self.age} жаста")

6-қадам. Бірнеше объект құру

p1 = Person("Aigerim", 19)
p2 = Person("Dias", 20)

6. Мысалдар

Мысал 1. Автокөлік класы

class Car:
    def __init__(self, model, year):
        self.model = model
        self.year = year
    
    def drive(self):
        print(self.model, "жүріп келеді!")

Мысал 2. Тіктөртбұрыш ауданы

class Rectangle:
    def __init__(self, a, b):
        self.a = a
        self.b = b
    
    def area(self):
        return self.a * self.b

Мысал 3. Студенттің толық ақпаратын шығару

class Student:
    def __init__(self, name, group):
        self.name = name
        self.group = group
    
    def show(self):
        print(f"Студент: {self.name}, топ: {self.group}")
