ПРАКТИКАЛЫҚ ЖҰМЫС №9

Тақырыбы: Функциялар құрастыру және пайдалану

1. Практикалық жұмыстың мақсаты

  • Python тілінде функция (function) ұғымын түсіну;
  • Функция анықтау, параметр қабылдау және мән қайтаруды меңгеру;
  • Бірнеше функция түрін (параметрсіз, параметрлі, мән қайтарушы) құрастыру;
  • Функцияны басқа кодтан шақыру дағдысын қалыптастыру;
  • Функцияларды пайдаланып алгоритмдік есептер шығару.

2. Қажетті бағдарламалар

  • Python 3.10+
  • PyCharm / VS Code / Jupyter Notebook

3. Теориялық бөлім

3.1 Функция деген не?

Функция — белгілі бір міндетті орындау үшін алдын ала жазылған код блогы.

Жалпы синтаксис:

def function_name():
    # функция ішіндегі код

3.2 Функция шақыру

def hello():
    print("Hello, Python!")

hello()

3.3 Параметрі бар функция

def greet(name):
    print("Сәлем,", name)

greet("Aruzhan")

3.4 Бірнеше параметр

def add(a, b):
    print(a + b)

add(5, 10)

3.5 Мән қайтаратын функция (return)

def square(x):
    return x * x

result = square(4)
print(result)

3.6 Әдепкі мән (default parameter)

def info(country="Kazakhstan"):
    print("Country:", country)

3.7 Функция ішінде функция шақыру

def multiply(a, b):
    return a * b

def area(a, b):
    return multiply(a, b)

print(area(3, 4))

4. Практикалық жұмыс қадамдары

1-қадам. Файл құру

Файл атауы: functions.py

2-қадам. Қарапайым функция

def hello():
    print("Сәлем, Python!")

hello()

3-қадам. Параметрі бар функция

def show_age(age):
    print("Жасы:", age)

show_age(18)

4-қадам. Return қолдану

def add(a, b):
    return a + b

print(add(5, 7))

5-қадам. Параметрді енгізу арқылы функция шақыру

def greet(name):
    print("Сәлем,", name)

user = input("Атыңыз: ")
greet(user)

5. Мысалдар

Мысал 1. Үшбұрыш периметрі

def perimeter(a, b, c):
    return a + b + c

print(perimeter(3, 4, 5))

Мысал 2. Максимум табу

def maximum(a, b):
    if a > b:
        return a
    return b

Мысал 3. Жұп/тақ функциясы

def is_even(n):
    return n % 2 == 0

Мысал 4. Тізімнің қосындысы

def total(lst):
    s = 0
    for x in lst:
        s += x
    return s
