ПРАКТИКАЛЫҚ ЖҰМЫС №7

Тақырыбы: Кортеждер мен жиындармен есептер шығару (tuple, set)

1. Практикалық жұмыстың мақсаты

  • Python тілінде кортеж (tuple) және жиын (set) құрылымдарының ерекшеліктерін түсіну;
  • Кортеждің өзгермейтін (immutable) қасиетін көрсету;
  • Жиынмен (set) жұмыс істеу: қосу, жою, біріктіру, қиылысу;
  • Дубликаттарды жою және бірегей элементтерді табу;
  • Кортеждер мен жиындарды қолданып практикалық есептер шығару.

2. Қажетті бағдарламалар

  • Python 3.10+
  • PyCharm / VS Code / Jupyter Notebook

3. Теориялық бөлім

3.1 Кортеж (tuple)

Tuple деген не?

Кортеж — тізімге ұқсас мәлімет құрылымы, бірақ өзгермейді.

numbers = (10, 20, 30)

Tuple ерекшеліктері

  • элементтері өзгермейді;
  • индекстеу бар;
  • жылдам жұмыс істейді.

Tuple элементтеріне қол жеткізу

print(numbers[0])
print(numbers[-1])

3.2 Жиын (set)

Set деген не?

Жиын — бірегей элементтерден тұратын, ретсіз мәлімет құрылымы.

fruits = {"apple", "banana", "orange"}

Негізгі операциялар

1) Элемент қосу
fruits.add("kiwi")
2) Элемент жою
fruits.remove("banana")
3) discard() — жою, қате шығармайды
fruits.discard("apple")
4) Біріктіру
set1 | set2
5) Қиылысу
set1 & set2
6) Айырмашылық
set1 - set2

4. Практикалық жұмыс қадамдары

1-қадам. Файл құру

Файл атауы: tuple_set.py

2-қадам. Tuple құру

colors = ("red", "green", "blue")
print(colors)

3-қадам. Set құру

numbers = {1, 2, 3, 3, 4, 5}
print(numbers)  # Қайталауды өздігінен алып тастайды

4-қадам. Қосу және жою

numbers.add(10)
numbers.discard(2)

5-қадам. Жиындармен операциялар

a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)  # біріктіру
print(a & b)  # қиылысу
print(a - b)  # айырмашылық

5. Мысалдар

Мысал 1. Tuple индекстеу

months = ("Jan", "Feb", "Mar")
print(months[1])

Мысал 2. Дубликаттарды автоматты жою

data = [1, 2, 2, 3, 4, 4, 5]
unique = set(data)
print(unique)

Мысал 3. Ортақ және ерекше элементтер

set1 = {1, 2, 3, 4}
set2 = {3, 4, 5}

print(set1 & set2)   # 3,4
print(set1 - set2)   # 1,2

6. Практикалық тапсырмалар

Тапсырма 1. Кортеж құру

Келесі мәліметтерден tuple жасаңыз:

name, age, city = ("Aruzhan", 18, "Taraz")

Жеке-жеке шығарыңыз.

Тапсырма 2. Tuple элементтеріне қол жеткізу

Кортеж:

nums = (10, 20, 30, 40, 50)

Шығарыңыз:

  • бірінші элемент
  • соңғы элемент
  • ортасындағы элемент

Тапсырма 3. Тізім → Жиын

Берілген тізімнен жиын жасаңыз, қайталанатындарды алып тастаңыз: 

lst = [2, 2, 2, 5, 7, 7, 8]

Тапсырма 4. Элемент қосу және жою (set)

Жиын:

cities = {"Taraz", "Astana", "Almaty"}
  • "Shymkent" қосу
  • "Astana" жою
  • "Kostanay" жою (қате шықпау керек → discard())

Тапсырма 5. Жиындардың айырмашылығын табу

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

Табу:

  • қиылысу
  • біріктіру
  • айырмашылық (a - b)

Тапсырма 6. Бірегей сөздер

Пайдаланушы бірнеше сөз енгізеді.
Бірегей сөздерді ғана көрсетіңіз.

Тапсырма 7. Ортақ студенттер

Екі топтағы студенттердің жиындары:

group1 = {"Ali", "Dana", "Aruzhan"}
group2 = {"Dana", "Arman", "Ali"}

Шығарыңыз:

  • ортақ студенттер
  • тек group1-ге тән студенттер
  • тек group2-ге тән студенттер

Тапсырма 8. Tuple unpacking

info = ("Python", 1991, "Guido van Rossum")

Айнымалыларға бөліп алып, шығарыңыз.

Тапсырма 9. Сан жиынының статистикасы

Жиындағы ең үлкен, ең кіші және элементтер санын анықтаңыз.

Тапсырма 10. Қос жиын арқылы жаңа жиын құру

Пайдаланушы екі жиын енгізеді.
Оларды біріктіріп, қайталамай жаңа жиын құру.

7. Қателер және шешімдер

Қате Себебі Шешімі
TypeError: 'tuple' object does not support item assignment Кортеж өзгермейді Жаңа кортеж құру
KeyError remove() әдісі жоқ элементті жоюға тырысады discard() қолдану
Жиын ретсіз Индекс жоқ set — ретсіз құрылым екенін түсіну
Дубликат жоғалуы set қолданғанда Қажет болса list қолдану

    4. Tuple элементін неге өзгертуге болмайды?
