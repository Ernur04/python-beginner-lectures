Лекции по Python

Изучайте Python шаг за шагом: от основ до профессионального уровня.

1 лекция. Python тіліне кіріспе. Орнату және IDE (IDLE, Jupyter, PyCharm)

1. Python тіліне кіріспе

Python — қазіргі таңда ең танымал, кең таралған, әмбебап бағдарламалау тілдерінің бірі. Оны 1989 жылы голландиялық программист Гвидо ван Россум жасап, 1991 жылы алғашқы нұсқасын шығарған.
Python тілінің ерекшеліктері: қарапайым синтаксис, кроссплатформалық, үлкен кітапхана, үлкен қауымдастық.

1.2. Python тілінің негізгі ерекшеліктері

  • Оқуға жеңіл синтаксис
  • Интерпретацияланатын тіл
  • Кросс-платформалық
  • Үлкен стандартты кітапхана
  • Үлкен қауымдастық

1.3. Python қолданылатын салалар

  • Data Science — NumPy, Pandas
  • Машиналық оқыту — TensorFlow, Scikit-Learn
  • Web — Django, Flask
  • Автоматтандыру
  • Мобильді және Desktop қосымшалар — Kivy, PyQt

2. Python орнату

  • Windows: python.org → Download → Add Python to PATH
  • Тексеру: python --version
  • Linux: sudo apt install python3 python3-pip
  • macOS: brew install python3

3. Python интерпретаторы (REPL)

Python орнатылғаннан кейін терминалға python деп жазу арқылы ашылады:
>>> print("Hello, Python!")

4. IDE түрлері

  • IDLE — Python-мен бірге орнатылады
  • Jupyter Notebook — интерактивті талдау ортасы
  • PyCharm — кәсіби IDE

4.1. IDLE

IDLE — Python-ның стандартты қарапайым редакторы. Run Module (F5) арқылы кодты орындауға болады.

4.2. Jupyter Notebook

Орнату: pip install notebook
Бастау: jupyter notebook
Артықшылықтары: интерактивті ұяшықтар, графиктер, мәтін, формулалар

4.3. PyCharm

JetBrains компаниясының кәсіби IDE-си.
Орнату: Community Edition нұсқасы тегін.
Артықшылықтары: авто-толықтыру, қате табу, Git-пен жұмыс.

5. Python файлының құрылымы

Python бағдарламалары .py кеңейтімімен сақталады:

print("Hello Python")

6. Практикалық тапсырмалар

  • Терминалда арифметикалық операция орындау
  • IDLE-де бірінші бағдарлама жазу
  • Jupyter-де екі ұяшық құру
  • PyCharm-де input() қолдану

Бұл лекцияда Python орнату, REPL қолдану, IDLE, Jupyter және PyCharm IDE-лерімен жұмыс қарастырылды.
