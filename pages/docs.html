Официальная документация Python (для обучения)

1. Введение: Что такое Python?

Python — это интерпретируемый, высокоуровневый язык программирования общего назначения, созданный Гвидо ван Россумом. Он был впервые выпущен в 1991 году.

Философия дизайна Python подчеркивает удобочитаемость кода с помощью значительных отступов.

# Пример "Hello, World!"
print("Hello, World!")

2. Установка и Настройка

Рекомендуется использовать последнюю стабильную версию Python 3. Вы можете скачать установщик с официального сайта python.org.

Обязательно отметьте "Add Python to PATH" (Добавить Python в PATH) во время установки в Windows.

Проверка установки

$ python --version
Python 3.11.5

3. Базовый Синтаксис

В отличие от многих других языков, Python использует двоеточие (:) и отступы (обычно 4 пробела) для обозначения блоков кода.

Условные операторы

x = 10
if x > 5:
    print("x больше 5")
elif x == 5:
    print("x равно 5")
else:
    print("x меньше 5")

4. Типы данных и Структуры

Python имеет мощные встроенные структуры данных, такие как списки, словари, кортежи и множества.

Списки и кортежи

# Список (изменяемый)
my_list = [1, 2, 'a', 'b']

# Кортеж (неизменяемый)
my_tuple = (10, 20, 30)

Словари и множества

# Словарь (ключ-значение)
my_dict = {'name': 'Alice', 'age': 30}

# Множество (уникальные элементы)
my_set = {1, 2, 3, 3, 1} # Результат: {1, 2, 3}

5. Функции и Модули

Функции определяются с помощью ключевого слова def и могут принимать аргументы, возвращать значения и иметь аннотации типов.

def add_numbers(a: int, b: int) -> int:
    """Возвращает сумму двух чисел."""
    return a + b

import math
print(math.sqrt(16))

6. Объектно-Ориентированное Программирование (ООП)

Python полностью поддерживает ООП, включая наследование, полиморфизм и инкапсуляцию.

class Dog:
    def __init__(self, name):
        self.name = name
    
    def bark(self):
        return f"{self.name} говорит 'Гав!'"

my_dog = Dog("Rex")
print(my_dog.bark())

7. Работа с файлами

Для работы с файлами в Python используется функция open(), а ключевое слово with гарантирует, что файл будет закрыт автоматически, даже если произойдет ошибка.

Чтение из файла

with open('data.txt', 'r') as file:
    content = file.read()
print(content)

Запись в файл

with open('output.txt', 'w') as file:
    file.write("Это новая строка.")

8. Обработка исключений

Исключения (ошибки во время выполнения) обрабатываются с помощью блоков try, except, else и finally. 

try:
    result = 10 / 0
except ZeroDivisionError:
    print("Ошибка: Деление на ноль!")
except Exception as e:
    print(f"Другая ошибка: {e}")
else:
    print(f"Результат: {result}")
finally:
    print("Выполняется всегда.")

9. Стандартная библиотека Python (Stdlib)

Stdlib — это обширный набор модулей, доступных "из коробки" (без дополнительной установки). Ключевые модули включают os (взаимодействие с ОС), sys (параметры среды), json (работа с JSON), datetime (работа со временем) и re (регулярные выражения).

Пример использования модуля datetime для работы со временем: 

import datetime

now = datetime.datetime.now()
print(now.strftime("%Y-%m-%d %H:%M:%S"))

10. Виртуальные окружения (Virtual Environments)

Виртуальное окружение (venv) — это изолированная среда Python, позволяющая управлять зависимостями для разных проектов отдельно, избегая конфликтов версий.

Создание и активация

Чтобы создать окружение, используйте команду python -m venv my_env. Для активации в Windows: 

my_env\Scripts\activate

В Linux/macOS:

source my_env/bin/activate
