# Python Beginner Lectures (Платформа для изучения Python)

## 📌 Описание проекта
Этот проект представляет собой полноценную образовательную веб-платформу, предназначенную для изучения языка программирования Python начинающими разработчиками. Сайт содержит структурированный учебный материал, разделенный на лекции, практические задания, видеоуроки и шпаргалки. Платформа создана с упором на удобство пользовательского интерфейса (UX) и поддерживает многоязычность.

## 📁 Структура кодовой базы
Проект реализован на основе классической архитектуры фронтенда (Static Website) с использованием HTML, CSS и Vanilla JavaScript.

- **`index.html`** — Главная страница (Landing Page). Содержит приветственный баннер, навигационное меню, превью разделов (лекции, видеоуроки, шпаргалки) и контактную информацию в футере.
- **`pages/`** — Директория с основными разделами сайта (всего 35 HTML-страниц):
  - **15 лекций** (`lecture_2.html` - `lecture_15.html`, плюс базовая `lecture.html`), охватывающих темы от введения в Python и базовых типов данных до более сложных концепций.
  - **15 практических работ** (`practice_2.html` - `practice_15.html`), направленных на закрепление теоретических знаний.
  - **Дополнительные материалы**: `cheatsheet.html` (шпаргалка), `videolesson.html` (видеоуроки), `docs.html` (документация), `history.html` (история языка), `faq.html`.
- **`js/`** — Логика клиентской части:
  - **`script.js`** — Обработка UI-событий: управление модальным окном (для удобного скачивания файлов), отслеживание скролла для отображения кнопки "Наверх" и реализация плавной прокрутки.
  - **`translations.js`** — Модуль мультиязычности (i18n). Асинхронно подгружает JSON-файлы локализации через Fetch API, обновляет текстовый контент DOM-элементов по ключам `data-i18` и сохраняет выбранный язык в `localStorage`.
- **`locales/`** — Содержит файлы переводов в формате JSON для динамической смены языка (поддерживаются Казахский, Русский и Английский).
- **`css/`** — Таблицы стилей (`style.css`, `index.css`), обеспечивающие адаптивную верстку, современный дизайн карточек и стилизацию интерактивных элементов.
- **`files/`** — Архивы и документы (например, лекции и практика в формате `.docx`), доступные для скачивания через модальное окно.
- **`image/`** — Статические медиа-ресурсы, изображения, иконки соцсетей.

## 🚀 Основной функционал
1. **Динамическая многоязычность**: Переключение между языками (KZ, RU, EN) происходит мгновенно без перезагрузки страницы благодаря скриптам загрузки локализаций.
2. **Модальные окна загрузок**: Централизованный интерфейс для быстрого доступа и скачивания лекций и практических работ в форматах документов.
3. **Интеграция медиа**: Встроенные iframe-плееры с видеоуроками на YouTube.
4. **Адаптивный и современный UI**: Использование Grid/Flexbox для красивого отображения карточек лекций на различных устройствах.
5. **Навигация**: Удобное меню, плавная прокрутка и четкая иерархия страниц.

## 🛠 Технологический стек
- **HTML5**: Семантическая верстка.
- **CSS3**: Стилизация, анимации, адаптивный дизайн (Responsive Web Design).
- **JavaScript (ES6+)**: Асинхронные запросы (`async/await`, `fetch`), работа с DOM и `localStorage`.

## 💻 Запуск проекта
Проект состоит из статических файлов и не требует установки зависимостей (например, Node.js или базы данных). 
1. Для базового просмотра страниц достаточно открыть файл `index.html` в любом браузере.
2. **Важно:** Поскольку система перевода (многоязычность) использует Fetch API для загрузки локальных JSON-файлов, при открытии файлов напрямую через протокол `file://` могут возникнуть CORS-ошибки. Рекомендуется запускать проект через локальный веб-сервер (например, расширение **Live Server** в VS Code, встроенный сервер Python `python -m http.server`, или любой другой).
